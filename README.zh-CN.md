## 隐私和支持

当前 Mac 版只在本机处理捕获画面，不录制、不上传、不捕获音频，也没有分析组件。系统授权整个源窗口，应用再本地裁剪。仅保存语言偏好。

## 使用限制

一次支持一个源窗口。源窗口布局变化可能需要重新框选。最小化、关闭、受保护内容或锁屏可能使画面中断或停留。暂停会保留最后一帧。本测试版不适合作为安全关键监控或报警系统。
