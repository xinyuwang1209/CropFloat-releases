# CropFloat

**让窗口中的任意区域，实时悬浮。**

![CropFloat 功能示意：框选源窗口区域，在其他窗口上方显示实时浮窗。](docs/assets/overview-zh-CN.svg)

CropFloat 是一个 macOS 实时区域浮窗工具。它捕获你选择的窗口，将框选区域显示在可移动、缩放的置顶小窗中，并随源画面更新。

例如，把浏览器里的摄像头画面单独放在一角，主窗口继续写文档；或把耗时任务的进度条放在眼前，省去反复切换窗口。

## 怎么用

| ① 选择窗口 | ② 框选区域 | ③ 悬浮显示 |
| :--- | :--- | :--- |
| 点击「选择窗口…」，通过系统选择器授权。 | 在实时预览中拖动，框出需要的画面。 | 点击「置顶所选区域」，移动或缩放浮窗。 |

应用默认英文，可在界面或菜单中切换为简体中文。

## 常用控制

- **鼠标穿透**：点击浮窗下方的内容；从菜单栏恢复浮窗操作。
- **暂停与继续**：暂停实际捕获，保留最后一帧，随时恢复。
- **帧率**：选择每秒 15 或 30 帧。
- **停止捕获**：从菜单栏停止，或关闭浮窗。仅关闭编辑窗口不会停止捕获。

## 隐私

画面只在本机处理，不录制到磁盘、不上传、不捕获音频，也没有分析或追踪组件。仅保存语言偏好。

系统授权的是**整个源窗口**，应用再在本机裁剪显示区域。当前版本运行于系统沙盒，没有网络访问权限。

[阅读完整隐私政策](privacy-zh-CN.html)

## 当前限制

- 一次支持一个源窗口和一个浮窗，退出后不会恢复选区。
- 选区固定在窗口坐标上，不会追踪内容；滚动或改变布局后可能需要重新框选，窗口比例大幅变化后应重新选择窗口。
- 源窗口最小化、关闭、锁屏或受保护内容可能使画面中断或停留。不能把浮窗当成可靠的报警系统。
- 全屏、多显示器、辅助功能、长时间能耗及 macOS 14 兼容性仍需验证。捕获画面最长边上限为 1920 像素。
